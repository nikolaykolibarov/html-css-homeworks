# HTML & CSS Homeworks

Homework assignments and exercises from the Web Fundamentals HTML/CSS course, covering web development basics with HTML5 and CSS3.

## Topics Covered

| # | Topic | Description |
|---|-------|-------------|
| 1 | HTML5 Overview | Document structure, semantic elements, basic tags |
| 2 | HTML5 Other Tags | Media elements, links, text formatting |
| 3 | HTML5 Tables | Table structure, rows, columns, spanning |
| 4 | HTML5 Forms | Input types, form validation, form elements |
| 5 | CSS3 Overview | Selectors, properties, styling basics |
| 6 | CSS3 Presentation | Colors, fonts, backgrounds, borders |
| 7 | CSS3 Layout and Positioning | Box model, flexbox, positioning, floats |
| 8 | CSS3/SASS Transformations | Transforms, transitions, SASS preprocessing |

## How to Run

Simply open any `.html` file in a web browser to view the result.

For SASS files:
```bash
# Install SASS
npm install -g sass

# Compile SASS to CSS
sass input.scss output.css
```

> **Note:** These are course homeworks from Software University (SoftUni). They are intended for educational purposes and demonstrate HTML5 and CSS3 fundamentals.
